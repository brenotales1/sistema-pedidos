## 1. O que já existia antes do início do semestre (não conta como incremento)

- Definição do tema e do problema do TCC relacionados ao controle de estoque de uma empresa de comunicação visual.
- Levantamento e definição inicial dos requisitos do sistema.
- Modelagem inicial do sistema e estrutura do banco de dados.
- Implementação inicial da aplicação web para gerenciamento de pedidos, clientes e estoque.
- Estrutura inicial do código-fonte e das funcionalidades desenvolvidas no contexto do TCC.

*Esses artefatos foram desenvolvidos anteriormente ao início do Laboratório e serão considerados como produto-base do TCC, não como incremento desenvolvido durante o semestre. A versão pré-existente permitia realizar as operações básicas de cadastro e consulta relacionadas a clientes, pedidos e materiais/estoque. As integrações com WhatsApp e código de barras ainda não estavam implementadas antes do início do Laboratório.*

---

## 2. O que será construído durante o Laboratório (conta como incremento)

- Integração de uma API de WhatsApp para envio de notificações aos clientes relacionadas ao andamento dos pedidos.
- Implementação do fluxo de disparo das notificações a partir de eventos definidos no sistema.
- Integração de uma API/serviço para identificação de materiais por código de barras.
- Implementação do registro de entrada de materiais no estoque utilizando o código de barras.
- Validações e tratamento de erros das duas integrações.
- Testes das novas funcionalidades, incluindo testes de integração e evidências de execução.
- Versionamento, revisão do código e documentação das funcionalidades desenvolvidas.
